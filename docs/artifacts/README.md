# Mini-Synth Project Artifacts

This directory contains the permanent knowledge base for the Mini-Synth project. It serves as the source of truth for the project's state, design principles, and engineering standards.

## Cold Start Instruction for AI Agents

> [!IMPORTANT]
> To pick up work on this project or synchronize context in a new session, you **MUST** read the following files in order:
> 1.  [PROJECT_STATE.md](PROJECT_STATE.md): Current system architecture, implemented features, and roadmap.
> 2.  [MASTER_PLAN.md](MASTER_PLAN.md): Technical specifications and mandatory development workflows.
> 3.  [guides/DESIGN_GUIDE.md](guides/DESIGN_GUIDE.md): Visual and UX standards (FL Studio aesthetic).
> 4.  [guides/ENGINEERING_STANDARDS.md](guides/ENGINEERING_STANDARDS.md): Performance and code quality requirements.

## Directory Structure

- `PROJECT_STATE.md`: High-level summary of the engine and UI status.
- `MASTER_PLAN.md`: Technical math, JNI specs, and mandatory sequential review workflow.
- `guides/`: Permanent reference documents for design, workflow, and engineering.
- `milestones/`: Historical record of feature implementations, including task lists and walkthroughs.
- `maintenance/`: Logs of stability refinements and engineering reviews.
